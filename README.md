# シンプルToDo

メールアドレスとパスワードでログインして、自分だけのToDoを管理するWebサービスです。スマホでもパソコンでも見やすい画面になっています。

## 使用したプロンプト
```
ToDo管理のWebサービスを作ってください。確認や質問はせず、最後まで一度で作り切ってください。

【作りたいもの】
複数の人が使えるToDoサービスです。スマホでもパソコンでも見やすい画面にしてください。

【ほしい機能】
- メールアドレスとパスワードでユーザー登録・ログインができる
- ログインした人が、自分のToDoを追加・編集・削除・完了にできる
- ToDoには、タイトル・メモ・期限日を付けられる
- データはデータベースに保存する(ブラウザを閉じても消えない)
- パスワードを忘れたとき用に、プロフィール画面でユーザー名やメールアドレスを変更できる

【見た目】
- 白を基調にした、すっきりした見た目
- ボタンは大きめで押しやすく

【完成の条件】
- 私のパソコンでそのまま動かせる状態にしてください
- 起動方法を、最後に手順書として書いてください
```

## 機能

- ユーザー登録・ログイン・ログアウト(メールアドレスとパスワード)
- ToDoの追加・編集・削除・完了(タイトル、メモ、期限日)
- 期限切れと今日までのToDoに目印を表示
- プロフィール画面でユーザー名・メールアドレス・パスワードを変更
- データはSQLiteのファイル(`data/todo.db`)に保存されるため、ブラウザやサーバーを閉じても消えません

## 必要なもの

- Node.js 22.13以上(24以上を推奨)
  - 確認方法: ターミナルで `node -v`
  - 入っていない場合は https://nodejs.org/ja から LTS 版をインストールしてください

`npm install` は不要です。外部パッケージを使っていません。

## 起動手順

1. ターミナルでこのフォルダに移動します。

   ```bash
   cd oneshot-todo
   ```

2. 起動します。

   ```bash
   npm start
   ```

   (`node server.js` でも同じです)

3. 次のように表示されたら起動完了です。

   ```
   ToDoサービスを起動しました: http://127.0.0.1:3000
   ```

4. ブラウザで http://localhost:3000 を開きます。

5. 「新規登録」タブからユーザー名・メールアドレス・パスワード(8文字以上)を入力して登録すると、すぐに使い始められます。

停止するときは、ターミナルで `Ctrl + C` を押します。次回起動したときも、登録したユーザーとToDoはそのまま残っています。

## スマホから見る場合(同じWi-Fi内)

初期設定では自分のパソコンからしか開けません。同じWi-Fiのスマホから確認したいときだけ、次のように起動します。

```bash
HOST=0.0.0.0 npm start
```

スマホのブラウザで `http://<パソコンのIPアドレス>:3000` を開きます。信頼できるネットワークでのみ使ってください(通信は暗号化されません)。

## 設定(環境変数)

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `PORT` | `3000` | 待ち受けるポート番号。3000が使用中なら `PORT=3100 npm start` |
| `HOST` | `127.0.0.1` | `0.0.0.0` にすると他の端末からも接続できます |
| `DB_PATH` | `data/todo.db` | データベースファイルの場所 |
| `COOKIE_SECURE` | なし | HTTPSで公開する場合は `1` を指定 |

## データのバックアップとリセット

- バックアップ: サーバーを止めて `data/` フォルダをコピーします。
- 全データを消して最初からやり直す: サーバーを止めて `data/` フォルダを削除します。

## パスワードを忘れた場合

メールを送る機能はありません。ログイン中にプロフィール画面で変更できます。ログインできなくなった場合は、`data/` フォルダを削除してやり直してください(全データが消えます)。

## 構成

```
server.js        サーバー本体(API、認証、DB)
public/          画面(index.html / style.css / app.js)
data/todo.db     データベース(初回起動時に自動作成)
```

## セキュリティ面の対応

- パスワードは scrypt でハッシュ化して保存(平文では保存しません)
- ログインはHttpOnlyのCookieで管理(セッションの有効期間は30日)
- ログイン・登録の連続失敗を制限(10分間に10回まで)
- 自分以外のユーザーのToDoは、閲覧・変更・削除できません
- 他サイトからの不正なリクエスト(CSRF)を拒否
